# Copywriting — Dronwind Experience

## Capitulo 0 — Intro
**Duracion visual**: 3-5 segundos de lectura

```
[DRONWIND]          <- typewriter, letra por letra, font-size: 80-120px

Limpieza con drones

Sin riesgos. Sin andamios. Sin limites.
```

**Notas**:
- "DRONWIND" en Montserrat Black, tracking -2px
- El punto rojo sobre la "i" parpadea como cursor
- El tagline aparece con stagger (0.1s entre linea)

### Skip / Exit

```
Prefieres ir directo al grano?
[Ver servicios]  [Contactar]
```

---

## Guia de Voz

- **Tono**: Profesional pero cercano. Tecnologico pero humano.
- **Evitar**: Jerga tecnica excesiva, lenguaje corporativo frio
- **Usar**: "Tu", "Tu edificio", verbos de accion, numeros concretos
- **Longitud maxima por bloque**: 6 palabras por linea en titulos
